# DeCaf 1.0

Initial GitHub-distributed VSIX release.

## Included

- DeCaf squid espresso icon.
- Local log detection.
- Temporary DeCaf view generation.
- Automatic DeCaf opening settings.
- Timeline gap markers.
- Gap navigation commands.
- Time-range view command with optional day/month/year dates.
- DeCaf color themes.
- Keyword highlighting.
- Theme preview command.
- Local-only privacy posture.

## Install

Install `decaf-1.0.vsix` from VS Code using `Extensions -> ... -> Install from VSIX...`.
