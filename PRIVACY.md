# Privacy

DeCaf processes logs locally inside VS Code.

## What Leaves Your Machine

Nothing from DeCaf is intentionally sent outside your machine.

The extension does not include network code, telemetry, analytics, AI calls, server calls, or cloud processing.

## What Happens To Your Logs

When DeCaf opens a log, it creates a temporary local view for easier reading. The original file remains untouched.

DeCaf does not upload logs and does not bundle sample logs in the VSIX.

## GitHub Release Contents

This release repo is intended to contain only:

- `decaf-*.vsix`
- `README.md`
- `PRIVACY.md`
- `RELEASE_NOTES.md`
- `SHA256SUMS.txt`

No private development logs, customer logs, or test samples should be published here.
